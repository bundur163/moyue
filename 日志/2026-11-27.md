## 二、执行过程

1. **清理本地产物**：删除旧 Electron `win-unpacked`、7zS 自解压包、旧 Electron EXE、IExpress/NSIS 临时目录、Tauri 测试构建、npm/Electron 缓存与临时安装目录；仅保留最终 Windows 安装包、便携版、校验文件，并统一放到 `release/`。
2. **macOS 工程**：在 Tauri 工程中增加 `bundle.macOS`（最低 macOS 11.0）、`icons/icon.icns`、`build:mac` 脚本；新增 `.github/workflows/build-tauri-macos.yml`，在 `macos-latest` 上安装 `aarch64-apple-darwin` + `x86_64-apple-darwin`，构建 Universal DMG。
3. **macOS 原生打印**：增加 Tauri 命令 `print_document`，macOS 调用 `WebviewWindow::print()`（WKWebView 原生打印）；前端在 macOS Tauri 下优先调用该命令，失败回退 `window.print()`。
4. **首次 macOS 构建失败**：Tauri 生成 DMG 后会清理 `.app`，工作流还在查找 `.app` 生成 ZIP，导致 `Prepare macOS release files` 失败；改为只发布 DMG 并生成 SHA-256，重新构建成功。
5. **Windows 重新构建**：同步最新的单文件 HTML 与 `print_document` 命令，`windows-latest` 构建成功；新产物 `moyue.exe` 8,971,776 字节、NSIS 安装包 1,961,789 字节。
6. **发布**：v1.3.0 Release 更新为 Windows 便携/安装包、macOS Universal DMG、各自 SHA-256；Release 名称改为「墨阅 v1.3.0（Tauri / 系统 WebView）」；旧 Electron v1.2.0 Release/tag 与旧 macOS 工作流已删除。
