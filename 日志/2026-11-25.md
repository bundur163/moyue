## 二、执行过程

1. **选型**：阅读器保持 `Markdown阅读器.html` 单一事实来源，增加 `desktop/` Electron 33 桌面壳；主进程只负责窗口、菜单、外部链接与打印桥接，渲染层原样加载 HTML。
2. **Windows 打包尝试**：
   - Electron 45 + `electron-builder` portable：NSIS makensis 创建 126MB mmap 失败；
   - 降到 Electron 33：payload 96MB，仍在 makensis mmap 失败；
   - IExpress：无法保留 `locales/`、`resources/` 目录结构，不可用；
   - 最终采用 **7zS.sfx + 7z 归档**：应用目录压缩为 78MB 7z，拼接 7zS.sfx 与 `RunProgram=Moyue.exe` 配置，生成 81MB 单文件 EXE。
3. **Windows 验证**：单文件 EXE 启动后 `Moyue.exe` 进程运行，主窗口标题为「墨阅」；生成 SHA-256 并上传 GitHub Release v1.2.0。
4. **macOS**：
   - `electron-builder` 明确拒绝在 Windows 构建 macOS；
   - `@electron/packager` 因 Windows 无符号链接权限跳过 darwin；
   - 改用 GitHub Actions `macos-latest` 构建 DMG/ZIP；首次 `macos-14` 运行被取消（runner 标签已退役），切换 `macos-latest` 后进入构建。
5. **GitHub**：新增 `.github/workflows/build-macos.yml`，提交桌面壳、图标、构建脚本与说明；创建 Release v1.2.0，上传 Windows 单文件与校验文件。
6. **macOS 构建完成**：`macos-latest` 上构建并直接上传 Release：`Moyue-1.2.0-macOS-arm64.dmg/.zip`、`Moyue-1.2.0-macOS-x64.dmg/.zip` 与 `SHA256SUMS-macos.txt`，全部成功。
7. **文档**：更新 README 桌面版入口、`desktop/README.md` 构建/签名说明；浏览器验收 87 项回归通过。
