# 验收文档：Markdown 阅读器

这是一份用于验收的 Markdown 文档，覆盖标题、段落、列表、表格、引用、代码块与任务列表。它会被排成多页，用来检查左侧预览、翻页、搜索和复制。

## 一、阅读体验

纸面阅读的核心是位置感。左侧缩略图告诉你「现在在哪」，右侧纸面告诉你「正在读什么」，页脚告诉你「还有多少」。这三件事不需要额外操作，打开文档就能看到。

阅读时，正文使用系统字体，行距偏松，段间距克制。标题与正文之间用留白分开，不依赖粗重的装饰线。代码块与表格各自有独立的横向滚动，不会把整页撑宽。

> 阅读器的本分是呈现内容，而不是展示功能。

## 二、分页规则

分页不是把文字切断，而是把内容块放到纸上：

1. 标题、段落、列表、代码块、表格都视为一个整体块；
2. 逐块测量高度，装入当前页，装不下就换下一页；
3. 单块高于整页时独占一页，并允许在页内滚动；
4. 页脚统一显示文档名与页码，不参与正文测量。

一个常见的 Markdown 段落可能有几百字。只要它没有超过一页，就会完整地留在同一页，不会被拦腰截断。真正需要跨页的长代码块，会单独占一页，避免阅读时来回滚动整篇文档。

## 三、搜索行为

在顶栏输入关键词后，阅读器会：

- 统计全篇命中数量；
- 自动跳到第一处命中所在的页；
- 在当前页用暖黄色标出所有命中；
- 用更深的橙色标出正在查看的那一处；
- 支持 Enter / Shift+Enter 或上下按钮循环切换；
- 命中位于页内滚动区域时，自动把文字滚到可视范围。

搜索不会改写正文结构，所以高亮不会混进复制的文字里。

## 四、复制行为

用鼠标在正文中拖选，按 Ctrl+C 或右键复制即可。选中状态由浏览器原生维护，阅读器不监听、不阻止、不替换选区事件。

可以复制的对象包括普通段落、标题、列表、表格单元格、代码块和引用。页脚、缩略图与工具栏不在正文选区中。

| 对象 | 是否可选中 | 备注 |
| --- | --- | --- |
| 段落 | 是 | 原生选区 |
| 标题 | 是 | 原生选区 |
| 表格 | 是 | 复制后按制表符分列 |
| 代码块 | 是 | 保留缩进 |
| 页脚 | 否 | 不属于正文 |
| 缩略图 | 否 | 纯预览 |

## 五、键盘操作

| 操作 | 快捷键 |
| --- | --- |
| 下一页 | → 或 PageDown |
| 上一页 | ← 或 PageUp |
| 首页 / 末页 | Home / End |
| 搜索 | Ctrl+F |
| 下一个 / 上一个命中 | Enter / Shift+Enter |
| 打开文件 | Ctrl+O |
| 清除搜索 | Esc |

如果正文里已经选中了文字，左右方向键优先交给浏览器处理选区，不会翻页。

## 六、代码块示例

```js
const paper = { width: 760, height: 1075 };

function paginate(blocks, contentHeight) {
  const pages = [];
  let page = [];
  let used = 0;

  for (const block of blocks) {
    const height = block.getBoundingClientRect().height;
    if (used + height > contentHeight && page.length) {
      pages.push(page);
      page = [];
      used = 0;
    }
    page.push(block);
    used += height;
  }

  if (page.length) pages.push(page);
  return pages;
}
```

上面这段代码只演示装箱思路。实际实现还要把外边距计入高度，并处理单个块高于整页的情况。

## 七、长段落检查

阅读是一种连续的注意力活动。排版的目标不是把页面填满，而是让每一行都容易进入下一行。过宽的行会让眼睛找不到下一行的起点，过窄的行会频繁换行，打断语义。适中的行宽、稳定的行距、清楚的层级，比任何装饰都重要。

同样的道理适用于翻页。翻页应当是阅读的停顿，而不是打断。页码、缩略图与键盘快捷键，只是把这个停顿变得可预期。读者知道自己在哪一页，也知道下一页大概是什么，就能继续读下去。

搜索则是另一种停顿：从连续阅读切换到查找。命中计数告诉读者「还有多少」，高亮告诉读者「在这里」，而翻页把两者连起来。搜索结束后，读者应该能回到原来的阅读位置，而不是被带到别处。

复制是最轻的停顿。选中、复制、回到文档，整个过程不需要工具栏。阅读器要做的，只是不挡路。
