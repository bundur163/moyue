## 5. 结论

- 需求 R1–R13 全部通过自动化验收（桌面壳另做 Windows 冒烟）；
- 原生选中与复制路径可用，复制内容与选区一致；
- 三档显示模式可用，选择写入 localStorage，再次打开文件会沿用；
- 手动缩放不覆盖已保存的显示偏好；
- 超长代码块按行拆分；超大表格/段落仍有页内滚动兜底；
- 大纲模式可切换、可点击跳页、当前项高亮，收起后仍进入连续滚动；
- 连续模式页尾接页首、滚动时页码同步，展开后回到当前单页；
- 单页滚轮可上下翻页，末页不越界；连续模式保持原生滚动；
- 打印准备生成逐逻辑页的 A4 纸张，打印媒体下隐藏应用界面，溢出页内容不被裁切；
- 单文件版与源码版行为一致（含大纲、连续模式与打印准备）；
- 未发现未捕获脚本异常。
- 桌面冒烟（Electron 备用）：Windows 单文件 `Moyue-1.2.0-Windows-x64.exe` 启动后 `Moyue.exe` 进程运行，主窗口标题为「墨阅」。
- 桌面冒烟（Tauri 当前主推）：`windows-latest` 构建成功，`moyue.exe` 8,984,064 字节、NSIS 安装包 1,962,319 字节；复制到本地磁盘启动后窗口标题「墨阅」，WebView2 CDP 验证页面版本 1.3.0、示例 4 页、三档显示模式与 localStorage 偏好。
- 便携 exe 直接从 `P:` 网络映射盘启动仍会失败（WebView2 不支持网络盘运行）；本地磁盘启动正常，安装包安装到 `%LOCALAPPDATA%` 可正常使用。
- macOS：本轮按用户要求暂停 Tauri 改造；v1.2.0 Electron DMG/ZIP 仍可用。

## 6. 未覆盖 / 已知限制

- Firefox / Safari 的搜索高亮降级未做自动化（这些浏览器不支持 CSS Custom Highlight API）；
- 数百页大文档的首次排版与连续模式内存占用未做基准测试；
- 相对路径图片在 `file://` 下无法加载，未作为缺陷处理；
- 触控板滚轮惯性与 800ms 冷却的体感只做了程序化 WheelEvent 验证，未做真机触控板测试；
- 显示偏好依赖 localStorage；禁用存储或清理站点数据后会回到整页模式；
- 打印版式通过 CSS 媒体模拟验证，未连接实体打印机；浏览器页眉页脚、背景图形选项需在打印对话框确认；
- 移动端触摸手势、打印排版不在本期范围。
